No third-party assets are used by STAR FALL. For the record, the actual sources
of everything the game plays or shows:

| Asset | Source | License |
|---|---|---|
| Sound effects (`assets/audio/sfx/*.wav`) | Generated by `tools/generate_phase1_audio.py` (Python standard library synthesis) | Original, this repository |
| Music and ambience (`assets/audio/music/*.wav`) | Generated by `tools/generate_music.py` and `tools/generate_phase1_audio.py` | Original, this repository |
| Runtime sound cues (shield, blaster, dash, landing, ...) | Synthesised at runtime by `core/star_fall/sf_audio.gd` | Original, this repository |
| Sprites, pixel font, UI | Drawn procedurally at runtime (`core/star_fall/sf_sprites.gd`, `sf_pixel_font.gd`, `sf_vela.gd`) | Original, this repository |
